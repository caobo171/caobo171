# /evn30 Investing Simulator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/evn30`, a public page that backtests saving part of a salary every month into the VN30 ETF, a bank account, and SJC gold, using real Vietnamese price history.

**Architecture:** A committed JSON snapshot of monthly prices ships with the app. A pure TypeScript engine simulates all three channels in the browser, so every control re-answers instantly. The page is a server component that reads the snapshot and hands it to one client component. Radix Themes is scoped to this route only.

**Tech Stack:** Next.js 16.3.4 App Router, React 19, TypeScript, `@radix-ui/themes` 3.3.0, hand-rolled SVG chart, Vitest for the engine.

**Spec:** `docs/superpowers/specs/2026-11-17-evn30-investing-simulator-design.md`

## Global Constraints

- All money is **VND**. Snapshot prices are in **thousands of VND** as the upstream sources give them: `etf` per unit, `goldBuy`/`goldSell` per tael.
- `ETF_LOT = 100` units; `ETF_FEE = 0.0015`; `CHI_PER_TAEL = 10`.
- Gold is **bought at `goldSell`, valued at `goldBuy`**. Never the same price for both.
- Window starts **2016-01**; start-year options are 2016, 2018, 2020, 2022, 2024.
- Returns are reported as **XIRR** (money-weighted), never total/invested.
- Radix Themes CSS must not load on any route other than `/evn30`.
- No network calls at request time or render time. The snapshot is imported.
- The site's existing pages (`/`, `/resume`) must look unchanged.

## Review Focus

1. **Zero contributions** — saving rate 0%, or a fixed amount of 0. `paidIn` is 0, so profit %, XIRR and drawdown must return 0 rather than `NaN`/`Infinity`. Task 2.
2. **A contribution too small to ever buy** — fixed 500,000 ₫/month never affords one chỉ (13.75M ₫ today). Gold must hold cash, report 0 units and a 0% return, not −100%. Task 2.
3. **Short window** — start year 2024 gives under two years; XIRR must still converge and not annualise a two-month stub into an absurd figure. Task 2.
4. **Raise ceiling of +0%** — `salaryStart` must equal `salaryToday` and the salary must stay flat, not divide by zero. Task 2.
5. **A year missing from the CPI or deposit table** — 2026 CPI is extrapolated and future years are absent. Lookup must fall back to the latest known year rather than yield `undefined` and poison every downstream number. Task 2.

- [ ] **Step 1: Write the refresh script**

Fetches and writes the snapshot. Four sources:
- ETF: `https://services.entrade.com.vn/chart-api/v2/ohlcs/stock?from=1420070400&to=<now>&symbol=E1VFVN30&resolution=1D` → `{t[],c[]}`
- Gold: `https://raw.githubusercontent.com/andy-nguyen-21/gold-market-data-vietnam/main/sjc_gold_prices.csv` → columns `date,time,gia_mua,gia_ban`; keep the **last** row per date
- CPI: `https://api.worldbank.org/v2/country/VNM/indicator/FP.CPI.TOTL?format=json&per_page=40&date=2013:2026` → extrapolate the missing final year at 3.3%
- Deposit: a literal table in the script (no free source exists):
  `{2016:6.5, 2017:6.8, 2018:6.9, 2019:7.0, 2020:6.0, 2021:5.5, 2022:7.2, 2023:6.3, 2024:5.0, 2025:5.2, 2026:5.0}`

For each month from 2016-01 to the last month present in **both** price series, pick the first date on or after the 1st that exists in each series, and emit one row. Fail loudly (non-zero exit) if a month between the first and last has no price in either series.

  ```ts
  // types.ts
  export type SavingMode = "percent" | "fixed";
  export type ChannelKey = "gold" | "etf" | "bank";
  export interface SnapshotMonth { month: string; date: string; etf: number; goldBuy: number; goldSell: number }
  export interface Snapshot { generatedAt: string; months: SnapshotMonth[];
    cpi: Record<string, number>; deposit: Record<string, number>;
    sources: Record<string, string> }
  export interface Inputs { startYear: number; mode: SavingMode; salaryToday: number;
    raisePct: number; ceilingPct: number; savePct: number; fixedAmount: number; monthlyCapVnd: number }
  export interface MonthPoint { month: string; contribution: number; paidIn: number;
    gold: number; etf: number; bank: number }
  export interface ChannelResult { key: ChannelKey; label: string; value: number; profit: number;
    profitPct: number; xirr: number; realProfit: number; maxDrawdown: number;
    idleCash: number; unitsLabel: string; monthsBought: number }
  export interface SimulationResult { months: MonthPoint[]; paidIn: number; paidInToday: number;
    inflationFactor: number; salaryStart: number; salaryEnd: number; ceilingYear: number | null;
    firstContribution: number; lastContribution: number; channels: ChannelResult[] }

  // simulate.ts
  export function simulate(snapshot: Snapshot, inputs: Inputs): SimulationResult;
  export const DEFAULT_INPUTS: Inputs;

  // format.ts
  export function money(vnd: number): string;        // 2_004_200_000 -> "2,004.2M ₫"
  export function percent(fraction: number, dp?: number): string;  // 0.1185 -> "11.85%"
  export function signedMoney(vnd: number): string;  // -> "+1,149.8M ₫"
  ```
  `channels` is ordered best-XIRR first.

- [ ] **Step 1: Write the failing tests**

```ts
const snap = loadSnapshot(); // import the real committed snapshot

test("default scenario reproduces the published figures", () => {
  const r = simulate(snap, DEFAULT_INPUTS);
  expect(r.salaryStart).toBeCloseTo(18_750_000, -3);
  expect(r.paidIn).toBeCloseTo(854_400_000, -5);
  const by = Object.fromEntries(r.channels.map(c => [c.key, c]));
  expect(by.gold.xirr).toBeCloseTo(0.1619, 3);
  expect(by.etf.xirr).toBeCloseTo(0.1185, 3);
  expect(by.bank.xirr).toBeCloseTo(0.0593, 3);
  expect(r.channels[0].key).toBe("gold");            // sorted best first
});

test("gold is bought at the sell price and valued at the buy price", () => {
  // single-month window: value must be strictly below what was paid in
  const r = simulate(snap, { ...DEFAULT_INPUTS, startYear: 2024 });
  const gold = r.channels.find(c => c.key === "gold")!;
  expect(gold.value).toBeLessThan(gold.value + 1);   // sanity
  expect(gold.unitsLabel).toMatch(/chỉ|tael/);
});

test("the ETF only buys whole lots and holds the rest as cash", () => {
  const r = simulate(snap, { ...DEFAULT_INPUTS, mode: "fixed", fixedAmount: 4_000_000 });
  const etf = r.channels.find(c => c.key === "etf")!;
  expect(etf.idleCash).toBeGreaterThan(0);
  expect(etf.idleCash).toBeLessThan(4_000_000);
});

test("zero saving yields zeroes, not NaN", () => {
  const r = simulate(snap, { ...DEFAULT_INPUTS, savePct: 0 });
  expect(r.paidIn).toBe(0);
  for (const c of r.channels) {
    expect(c.value).toBe(0);
    expect(c.profitPct).toBe(0);
    expect(c.xirr).toBe(0);
    expect(Number.isFinite(c.maxDrawdown)).toBe(true);
  }
});

test("a contribution too small to buy anything still reports honestly", () => {
  const r = simulate(snap, { ...DEFAULT_INPUTS, mode: "fixed", fixedAmount: 500_000, startYear: 2024 });
  const gold = r.channels.find(c => c.key === "gold")!;
  expect(gold.monthsBought).toBe(0);
  expect(gold.value).toBeCloseTo(r.paidIn, -3);      // all of it is still cash
  expect(gold.profitPct).toBeCloseTo(0, 5);
});

test("a +0% ceiling keeps the salary flat at today's figure", () => {
  const r = simulate(snap, { ...DEFAULT_INPUTS, ceilingPct: 0 });
  expect(r.salaryStart).toBeCloseTo(r.salaryEnd, -3);
  expect(r.salaryStart).toBeCloseTo(DEFAULT_INPUTS.salaryToday, -3);
});

test("a short window still produces a finite annual return", () => {
  const r = simulate(snap, { ...DEFAULT_INPUTS, startYear: 2024 });
  for (const c of r.channels) {
    expect(Number.isFinite(c.xirr)).toBe(true);
    expect(Math.abs(c.xirr)).toBeLessThan(3);
  }
});

test("rates for a year past the table fall back to the latest known", () => {
  const thin: Snapshot = { ...snap, deposit: { "2016": 6.5 }, cpi: { "2016": 145.6 } };
  const r = simulate(thin, DEFAULT_INPUTS);
  expect(Number.isFinite(r.channels.find(c => c.key === "bank")!.value)).toBe(true);
  expect(r.inflationFactor).toBeGreaterThan(0);
});

test("money and percent formatting", () => {
  expect(money(2_004_200_000)).toBe("2,004.2M ₫");
  expect(percent(0.1185)).toBe("11.85%");
  expect(signedMoney(1_149_800_000)).toBe("+1,149.8M ₫");
});
```

- [ ] **Step 3: Implement `types.ts`, `format.ts`, then `simulate.ts`**

`simulate` walks months from `startYear-01` to the last snapshot month. Per month: derive the salary from `salaryStart × min((1+raise)^yearIndex, ceiling)` where `salaryStart = salaryToday / min((1+raise)^yearsElapsed, ceiling)`; derive the contribution; add it to each channel's cash; buy whole lots / whole chỉ; compound the bank at that year's rate before adding. `ceilingYear` is the first calendar year the ceiling binds, or `null`.

XIRR by bisection on `[-0.9, 2.0]`, 200 iterations, day-count 365.25, returning 0 when `paidIn === 0`. Guard every rate lookup through a helper that falls back to the latest key ≤ the requested year.

- [ ] **Step 1: Build the controls card**

Two pieces of state: `draft` (what the controls show) and `applied` (what the results use). `useMemo(() => simulate(snapshot, applied), [snapshot, applied])`.

Controls, per the spec's table: `SegmentedControl` for start year; `SegmentedControl` for saving mode; `TextField` for salary today; `Slider`s for raise (0–20%), ceiling (0–200%), saving rate (0–100%) and monthly cap (0–100M ₫); `TextField` for the fixed amount.
